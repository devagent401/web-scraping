| ভেরিয়েবল | ডিফল্ট | উদ্দেশ্য |

## সমস্যা সমাধান

### পোর্ট 5000 ইতিমধ্যে ব্যবহারে
```bash
# বিকল্প ১: .env এ পরিবর্তন করুন
APP_PORT=5001

# বিকল্প २: পোর্ট ব্যবহারকারী প্রক্রিয়া বন্ধ করুন
lsof -i :5000
kill -9 <PID>
```

### ডাটাবেস সংযোগ ত্রুটি
```bash
# যাচাই করুন PostgreSQL চলছে কিনা
docker-compose logs postgres

# সংযোগ স্ট্রিং চেক করুন
cat .env | grep DATABASE_URL
```

### Redis সংযোগ ত্রুটি
```bash
# যাচাই করুন Redis চলছে কিনা
docker-compose logs redis

# সংযোগ পরীক্ষা করুন
redis-cli ping
```

### ডিপেন্ডেন্সি ইনস্টলেশন ব্যর্থ
```bash
# pnpm ক্যাশ সাফ করুন
pnpm store prune

# লক ফাইল সরান এবং পুনরায় ইনস্টল করুন
rm pnpm-lock.yaml
pnpm install
```

### TypeScript কম্পাইলেশন ত্রুটি
```bash
# ক্যাশ সাফ করুন
rm -rf dist

# পুনরায় তৈরি করুন
pnpm build
```

## উদাহরণ: নতুন ফিচার যোগ করা

1. `src/modules/yourmodule` এ নতুন মডিউল তৈরি করুন
2. `src/modules/yourmodule/yourmodule.spec.ts` এ টেস্ট যোগ করুন
3. প্রয়োজনে `prisma/schema.prisma` এ ডাটাবেস স্কিমা আপডেট করুন
4. চালান: `pnpm prisma:migrate`
5. চালান: `pnpm test`
6. চালান: `pnpm lint --fix`
7. পরিবর্তনগুলি কমিট করুন
